# The Gathering — v0.6.0-beta1

Исходники Android-приложения The Gathering для облачной сборки APK в GitHub Actions. Это **не готовый APK**. Основа — версия 0.5; настоящий звук продолжает обеспечивать Android Media3.

## Что изменилось

1. **Более медленное вертикальное листание стопки**: один жест перемещает максимум на один трек, без ускорения по скорости пальца. При отпускании стопка плавно фиксируется на ближайшей позиции.
2. **Растворяющиеся обложки**: передняя опускается лишь на 17% своей высоты и исчезает за счёт прозрачности. Следующая обложка увеличивается и проявляется постепенно. Переход к очередной позиции длится около 0,55 с, в том числе после незавершённого свайпа.
3. **Выбор трека только нажатием в режиме просмотра глубины**: после первого вертикального свайпа горизонтальные жесты по обложкам не переключают музыку даже при возвращении к нулевой глубине. Нажатие на видимую обложку запускает трек и возвращает обычный режим. Системный жест Android «Назад» закрывает режим просмотра глубины, но не само приложение.
4. **Названия обложек**: под стопкой при движении обложек перекрёстно проявляются названия предыдущего и следующего трека.
5. **Подсветка**: мягкий двухцветный радиальный градиент позади обложек, с деликатной анимацией прозрачности и масштаба только при воспроизведении. Это **не анализ музыки и не точная синхронизация с битом** — от полноценного аудиоанализатора отказались ради производительности.
6. **Лёгкий режим**: автоматически для устройств с `hardwareConcurrency <= 4`, с сообщением `deviceMemory <= 3`, либо при включённой системной настройке снижения анимаций. В лёгком режиме нет пульсации, отключены дорогие `backdrop-filter` у панели и кнопки, фильтр размытия канваса и маски на задних обложках.
7. **Перерисовка волны**: не более ~24 кадров в секунду при воспроизведении (до ~16 на слабых устройствах), существенно реже при паузе и существенно замедляется в фоне; повторно используются контекст canvas и линейный градиент.
8. **Ограничение декодирования в стопке**: в DOM держится только узкое окно вокруг выбранной глубины (обычно 5–7 карточек).

## Что может нагружать телефон (анализ исходников)

| Источник | Риск | Что сделано в 0.6 |
|---|---|---|
| `requestAnimationFrame` и canvas-волна | Повторные отрисовки даже при паузе | Разрежена частота, фоновые кадры пропускаются, кешируется градиент |
| `filter: blur` на большом градиенте за обложками | Большая перерисовываемая область GPU | Заменён готовым мягким радиальным градиентом и анимацией `opacity`/`transform` |
| `backdrop-filter` нижней панели и кнопки | Дорогостоящая композиция при перемещении соседних элементов | Отключается в лёгком режиме |
| Полноразмерные встроенные обложки из MediaStore | Память, декодирование, возможное убийство WebView системой | Ограничение количества одновременно отображаемых обложек; сохраняется риск от исходных больших изображений |
| CSS-маски задних обложек и тени | Дополнительные GPU-слои | Маски и фильтры отключаются в лёгком режиме |
| Очередь и библиотека | Много DOM-узлов при большой коллекции | Сохранены уже имевшиеся пакетная загрузка списка и ленивые изображения; требуется реальный тест на больших библиотеках |

### Сборка APK через GitHub

1. Распакуйте ZIP.
2. Откройте https://github.com/saturnfq-creator/TheGathering/upload/main и загрузите **содержимое** архива, включая папки `app`, `tests` и скрытую `.github`, если браузер позволяет.
3. Нажмите **Commit changes**, подождите завершения GitHub Actions.
4. После зелёной галочки откройте последнюю успешную сборку → **Artifacts** → скачайте `TheGathering-v0.6-beta1-APK`. Если `.github` не обновилась, имя артефакта может остаться прежним; проверьте номер `0.6.0-beta1` в исходниках.
5. Распакуйте артефакт, внутри находится `app-debug.apk`.

### Проверка

- `node tests/logic-smoke-test.cjs` — тесты очереди, состояния воспроизведения, навигации, однопозиционных вертикальных свайпов, блокировки горизонтальных свайпов и подписей.
- Chromium с мобильным экраном 393×852 — вручную проверены переход на одну обложку, ограничение длинного свайпа, горизонтальный свайп во время просмотра, выбор обложки нажатием, возврат к глубине 0. Ошибок JavaScript в этих сценариях не обнаружено.

**Ограничение:** APK не компилировалась в текущей среде, не запускалась на Android и не профилировалась на реальном слабом телефоне. Плавность, нагрев и утечки памяти требуется проверить на устройстве; причины вылетов точно диагностируются по `adb logcat` и профилю памяти. Изменения в браузерном интерфейсе сами по себе не гарантируют устранения всех лагов.

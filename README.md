# The Gathering v0.7.0-beta1

Это исходники Android-приложения **The Gathering**, а не готовый APK. Версия 0.7 построена на рабочем проекте 0.6. Существующий дизайн плеера и разделы библиотеки сохранены.

## Исправления в 0.7

1. **Вертикальная стопка с инерцией.** На сильный свайп вниз реагирует пролистыванием до четырёх обложек; движение вверх существенно сильнее — до девяти за жест. Отпущенная стопка плавно замедляется и остаётся на выбранной глубине. Горизонтальные свайпы при просмотре стопки по-прежнему не запускают песню; выбор только нажатием на обложку.
2. **Отличие просмотра от прослушивания.** Просматриваемые обложки чуть затемнены.
3. **Межальбомные переходы.** Кратковременный затухающий снимок предыдущей стопки смягчает замену групп обложек, когда выбранный или предыдущий трек относится к другому альбому. Снимок удаляется после перехода; постоянно дополнительная стопка не хранится.
4. **Очередь без задержки при отпускании.** Видимая строка фиксируется сразу; призрачная копия удаляется без ожидания 155 мс. Android Media3 получает одну команду перемещения трека вместо полной перестановки многотысячной очереди. Основная перестройка фоновой стопки отложена на короткое время после визуальной фиксации.
5. **Живое перемещение окна очереди.** В отличие от прежнего порогового жеста, верх окна физически следует за пальцем. Свайп за ручку вверх разворачивает, вниз сворачивает. При прокрутке списка вниз в его начале можно потянуть всё окно вниз, а обычная прокрутка списка не перехватывается.
6. **Свечение в цветах обложки.** Вместо размытия большого изображения используются три заранее заданных радиальных градиента. Новый Android-метод `requestCoverPalette` читает уменьшенную до ~80 пикселей копию обложки в фоновом потоке, усредняет цвета и отправляет два оттенка в интерфейс; результаты кешируются. На слабом устройстве палитра запрашивается только для воспроизводимого трека. Если изображение недоступно, остаётся запасная мягкая палитра. Пульсация медленная декоративная, **не привязана точно к ритму песни**.

## Проверки

- `node tests/logic-smoke-test.cjs`: очередь, воспроизведение, навигация, параметры инерции, интерфейсные контракты с Android.
- `python tests/browser-integration.py`: реальная мобильная разметка в Chromium: вертикальные жесты, инерционный возврат, запрет горизонтального листания в режиме просмотра, затухание межальбомного перехода, движение окна очереди за пальцем, отпускание строки без зависания, вызов одиночного переноса в Android.
- Синтаксис JS: `node --check app/src/main/assets/app.js`.

**Не проверено:** здесь нет установленного Android SDK/Gradle, поэтому новая версия не была собрана в APK, установлена на смартфон или профилирована на слабом устройстве. Быстродействие Media3, расход памяти и реальная плавность должны быть проверены после сборки.

## Как собрать APK без Android Studio

1. Распаковать архив, открыть [страницу загрузки файлов](https://github.com/saturnfq-creator/TheGathering/upload/main) и загрузить **содержимое** папки проекта в корень репозитория, включая скрытую `.github` и `tests`.
2. Нажать **Commit changes** — GitHub Actions запустит сборку.
3. Вкладка **Actions** → последняя успешная сборка → **Artifacts** → `TheGathering-v0.7-beta1-APK`. Если workflow `.github` не обновлён из-за скрытой папки, имя артефакта может остаться старым: проверяйте номер версии `0.7.0-beta1` в `app/build.gradle.kts`.
4. Распаковать артефакт; внутри `app-debug.apk`. Это отладочная APK. При несовпадении подписи со старой установкой потребуется удалить старую тестовую версию перед установкой новой (личные MP3 при этом не удаляются).

При ошибке сборки прислать **Build APK → последние строки лога**. При вылетах приложения для диагностики нужен Android logcat, а не только снимок экрана.

# The Gathering — 0.3.0-beta1

Обновление Android-плеера на основе работающей бета-версии 0.2. В архиве **исходный проект**, не готовый APK.

## Что изменилось

1. **Переходы обложек.** Четыре постоянные карточки в DOM вместо удаления и пересоздания всей стопки после каждого переключения. Передняя и задние карточки плавно переходят в новые позиции; фоновые изображения размываются только по кромке через маску. Быстрые свайпы сериализуются (не более одного ожидающего переключения), без конфликтующих анимаций.
2. **Таймлайн.** Между вызовами Media3 (приблизительно каждые 650 мс) текущая позиция интерполируется по монотонным часам. При отпускании пальца точка перемотки сохраняется на 1,6 сек, пока аудиодвижок не подтвердит новое положение. Это предотвращает кратковременный отскок к старой позиции.
3. **Размытие таймлайна.** Лёгкое размытие низкоразрешённого Canvas + прозрачный световой градиент без тяжёлой постоянной перерисовки.
4. **Поиск и библиотека.** Отдельный пункт поиска убран. Поле поиска находится сверху библиотеки. Поиск выполняется по исполнителю, альбому и названию песни.
5. **Навигация.** Библиотека ограничена сверху нижней навигационной панелью, панель навигации видна поверх содержимого; окно очереди по-прежнему раскрывается над интерфейсом.
6. **Меню трека.** Вертикальное троеточие у каждой строки: «Играть следующим», «Воспроизвести сейчас», «Добавить/убрать из избранного». Вызов «Играть следующим» переставляет Media3 очередь без остановки текущей песни.
7. **Альбомы.** Плитки 2 в ряд, по нажатию — отдельная страница с обложкой, треками и кнопками «▶ Слушать альбом» и «＋ Играть следующим». Первая кнопка начинает альбом с первого трека, затем остальная очередь идёт после его песен; вторая оставляет текущую песню играть и ставит песни альбома следующими.
8. **Фоновое пятно.** Динамический радиальный фиолетовый фон над шкалой убран, фон плеера сделан нейтральным. Стеклянная эстетика сохранена.

## Сборка APK через GitHub Actions

1. Распакуй `TheGathering_v0_3_GitHub.zip`.
2. Открой https://github.com/saturnfq-creator/TheGathering/upload/main
3. Перетащи **всё содержимое** распакованной папки, а не ZIP. Важно сохранить структуру `app/src/main/assets` и `.github/workflows`.
4. Нажми **Commit changes**. На вкладке **Actions** начнётся `Build The Gathering APK`.
5. После зелёной галочки открой сборку и скачай **TheGathering-v0.3-beta1-APK** из раздела Artifacts. Распакуй скачанный архив и установи `app-debug.apk`.

Если GitHub не передаст скрытую папку `.github`, предыдущий workflow останется рабочим и соберёт новые исходники из `app` (но название артефакта может остаться прежним).

При конфликте подписи тестовой APK может потребоваться удалить предыдущую версию приложения перед установкой новой. Музыкальные файлы при этом останутся, локальные данные приложения (например, избранное) могут быть потеряны.

## Проверка

- `node tests/logic-smoke-test.cjs` — логика перестановки очереди, «Играть следующим», воспроизведение альбома, события Media3 и интерполированная позиция.
- Отдельный браузерный сценарий проверен в Chromium с тестовой медиатекой: две плитки в строке, открытие альбома, поиск, меню трека, геометрия нижней навигации и сохранение DOM-обложек при переходах.

**Ограничения:** здесь не установлен Android SDK. APK не компилировался в этой среде; плавность и стабильность на конкретном телефоне ещё необходимо проверить после сборки в GitHub. Мы не заявляем, что вылеты полностью устранены без Android crash log.

# The Gathering 0.11.0 Beta

Обновлённый **Android-проект** музыкального плеера The Gathering на базе v0.10. ZIP — это **исходники для сборки через GitHub Actions**, не готовый APK.

## Что изменено в 0.11

1. **Горизонтальные свайпы и свечение.** Яркость и рисунок одобренной подсветки сохранены. При горизонтальном жесте контур плавно гаснет через CSS (без покадровой записи непрозрачности из JS), а после завершения перехода на новую обложку включается с задержкой примерно 250 мс и плавным проявлением примерно за 600 мс. При отменённом свайпе свечение восстанавливается после возврата карточки. Позиция свечения по-прежнему привязана к обложке.
2. **Фон под нижней панелью.** Библиотека теперь покрывает весь экран вплоть до нижнего края, включая область под полупрозрачной нижней навигацией. Отступы прокрутки оставлены, чтобы последние треки не перекрывались панелью.
3. **Таймлайн.** Незаполненная часть прозрачная и показывает фон плеера. Canvas рисует только заполненную часть прогресса. Контур, волна и статическое стеклянное свечение остаются.
4. **Табы библиотеки.** «Альбомы», «Исполнители», «Треки» теперь полупрозрачные, в стиле поля поиска. Активная вкладка выделена тёплым стеклянным контуром, без непрозрачной серой заливки.
5. **Убран плюс в правом верхнем углу библиотеки.** Автоматический поиск музыки в Android MediaStore остаётся прежним. Скрытый HTML-файловый импорт не удалялся из исходников, но видимой кнопки для него больше нет.
6. **Жесты очереди.** Свайп для сворачивания и разворачивания доступен не только на маленькой ручке, но и на заголовке, секциях «Сейчас играет» / «Дальше в очереди», карточке текущего трека и нижней строке. В частично раскрытой очереди свайп вверх от начала списка тоже расширяет её; в полностью раскрытой очереди список нормально прокручивается. Управление перестановкой через ручки не изменено.
7. **Shuffle.** Убрана анимация нажатия / вращения значка; яркое и тусклое состояния сохранены, реальное перемешивание не менялось.

## Оптимизация

- Во время горизонтального свайпа тени подсветки не перекрашиваются на каждом кадре.
- Ширина стопки считывается один раз на жест, не каждый кадр; классы переходов устанавливаются однократно.
- Отключена постоянная анимация масштаба большого фонового градиента при воспроизведении.
- В волне убрано размытие Canvas `shadowBlur` на каждой отрисовке; сохранено статическое CSS-свечение шкалы.
- Рисование волны планируется примерно с частотой 20 кадров/с на обычных устройствах, 12–13 кадров/с на маломощных; при перекрытом или невидимом плеере оно практически останавливается. При этом воспроизведение музыки не приостанавливается.
- Android сообщает в JS системный признак `ActivityManager.isLowRamDevice`; он используется вместе с существующими признаками слабого устройства для облегчённого режима.
- Просмотр альбомных обложек по-прежнему использует ограниченное число карточек; поиск и Media3 не переделывались.

Это **адресные меры**, а не доказательство устранения всех лагов. Быстродействие на реальном слабом устройстве и температуру можно достоверно оценить только после установки APK и тестирования (при необходимости с Android profiler/logcat).

## Проверка исходников

```bash
node --check app/src/main/assets/app.js
node tests/logic-smoke-test.cjs
python tests/browser-integration.py
python tests/v08-regressions.py
python tests/v09-regressions.py
python tests/v010-regressions.py
python tests/v011-regressions.py
```

Браузерные тесты проверяют внешний вид и жесты в Chromium. Это не заменяет Android Media3/WebView-тест на телефоне.

## Сборка APK без Android Studio

1. Распаковать этот ZIP и загрузить **всё содержимое** в корень репозитория https://github.com/saturnfq-creator/TheGathering/upload/main (включая скрытую `.github`).
2. Нажать **Commit changes**. Сборка должна запуститься в **Actions**.
3. После зелёной галочки скачать артефакт **TheGathering-v0.11-beta1-APK** в последнем запуске и распаковать `app-debug.apk`.
4. Установить APK и проверить плавность горизонтального свайпа, задержку свечения, область под навигацией и жесты очереди.

При ошибке сборки прислать текст из шага **Build APK**. APK здесь не собирался и не проверялся на физическом Android.

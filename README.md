# The Gathering — v0.5.0-beta1

**Исходный Android-проект** с GitHub Actions для сборки debug APK. Это не готовый APK: его необходимо собрать в GitHub Actions. Основа — рабочая ветка 0.4, уже успешно собиравшаяся у пользователя.

## Что изменено в 0.5

1. **Предыдущий трек свайпом вправо**: обложка теперь входит **СЛЕВА направо**, следуя за пальцем. При отменённом жесте все слои возвращаются плавно.
2. **Перетаскивание очереди**: pointer capture перенесён с перемещаемой строки на стабильный `#queueList`. `pointercancel`, `lostpointercapture`, потеря фокуса и системные отмены безопасно завершают жест. Подвешенных элементов после выхода за экран быть не должно.
3. **Ограничение перетаскивания**: копия трека остаётся внутри области очереди, даже если палец уходит далеко вверх/вниз. Автопрокрутка у обоих краёв и анимированное раздвигание строк сохранены.
4. **Устранение лага при отпускании**: порядок обновляется без немедленного пересоздания списка; копия трека мягко переходит к месту вставки и удаляется.
5. **Очередь как bottom sheet**: крестик убран. Свайп за верхнюю ручку/заголовок вверх разворачивает очередь на весь экран, вниз уменьшает или закрывает. Свайп вниз по списку при самом верху тоже может закрыть окно, обычная прокрутка по трекам остаётся независимой. Текущий трек остаётся сверху.
6. **Вертикальная стопка обложек**: свайп вниз показывает следующие обложки в глубине, вверх возвращает к началу. После отпускания глубина **сохраняется**. Нажатие на доступную обложку запускает её трек. Вертикальный просмотр **не меняет воспроизведение** сам по себе. Горизонтальные свайпы оставлены для музыкальной навигации. Одновременно в DOM не больше приблизительно 7–8 карточек (виртуализация).
7. **Android «Назад»**: системный жест от края и классическая кнопка идут через `OnBackPressedDispatcher` в историю интерфейса: меню трека → очередь → альбом → библиотека → фон приложения. На главном экране приложение сворачивается, музыкальный сервис остаётся работать. Убраны ненужные крестики из очереди и библиотеки.
8. **Таймлайн**: убрана отдельная прямоугольная вертикальная градиентная полоса. Подсветка теперь следует форме волны; остальной дизайн таймлайна не менялся.

### Сборка без Android Studio

1. Распакуйте ZIP.
2. Откройте https://github.com/saturnfq-creator/TheGathering/upload/main и загрузите **содержимое** архива, включая папки `app`, `tests` и при возможности скрытую `.github`.
3. Нажмите **Commit changes**. Workflow `Build The Gathering APK` запускается автоматически.
4. После зелёной галочки откройте последнюю успешную сборку в **Actions**, прокрутите к **Artifacts**, скачайте `TheGathering-v0.5-beta1-APK`. Если новая скрытая `.github` не загрузилась, артефакт может называться по-старому — тогда ориентируйтесь на `versionName = "0.5.0-beta1"` в `app/build.gradle.kts`.
5. Распакуйте скачанный артефакт; внутри `app-debug.apk` для установки на Android.

### Проверка

- `node tests/logic-smoke-test.cjs` — автоматические логические тесты очереди, времени воспроизведения, команд Media3, навигации и контракта виртуальной стопки.
- Chromium с мобильным экраном 393×852: проверены направленный свайп обложки справа налево/слева направо, открытие/закрытие/разворачивание очереди, перетаскивание трека выше границ окна с фиксацией позиции, возвращение глубины стопки, фиксация после отпускания и запуск выбранной обложки; ошибок JS в этих сценариях нет.

**Ограничение:** в текущей среде не собран APK и не проводились реальные тесты Android. Плавность на разных телефонах, системная жестовая навигация и долгосрочная стабильность требуют проверки в собранной версии. Вылеты при необходимости диагностируются через `logcat`.

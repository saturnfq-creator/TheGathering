# The Gathering — v0.4.0-beta1

Android-проект на базе реально собиравшейся версии 0.3. Содержит исходники и GitHub Actions workflow, **не готовый APK**.

## Исправления по 14 замечаниям

1. При неполном свайпе обложка мягко возвращается назад. Анимация использует трансформации и аппаратное композитирование, без пересоздания изображения во время жеста.
2. При свайпе вправо предыдущая обложка возвращается **с правой стороны**, двигаясь одновременно с пальцем. После отпускания она плавно приходит в центр; предыдущая обложка уходит в стек за ней.
3. Перетаскивание треков внутри очереди запускает автоматическую прокрутку у **верхней и нижней кромки** списка. По мере достижения низа длинная очередь автоматически догружается следующими блоками.
4. Во время перетаскивания за ручку «≡» отображается подвижная копия трека, а соседние строки плавно раздвигаются (FLIP-анимация). Реальный порядок Media3 обновляется при отпускании.
5. Убрана надпись «ПЕРЕТАСКИВАЙ ЗА ...».
6. Название на экране плеера прокручивается плавно **только если не помещается** в ширину.
7. Полностью удалены кнопка сердечка, управление избранным и пункт избранного в меню «⋮».
8. За стопкой обложек добавлено небольшое приглушённое тёплое свечение.
9. Граница заполняющей волны таймлайна стала заметнее: более высокая амплитуда, меньший blur и больший контраст. Блюр сохранён.
10. Пункт «Главная» переименован в «Плеер», значок заменён на ▶.
11. Нижняя панель навигации оформлена полупрозрачным стеклом с небольшим backdrop blur.
12. Таймлайн получил собственное мягкое свечение.
13. Убрана синяя подсветка нажатий и стандартный синий focus-ring. При навигации клавиатурой остаётся ненавязчивое тёплое выделение для доступности.
14. Убрано всплывающее сообщение после перестановки трека в очереди.

Воспроизведение через Media3, поиск, группировка по альбомам и страницы альбомов сохранены из версии 0.3. Остальные подсказки об ошибках аудио и импорте музыки сохранены, поскольку они полезны.

## Собрать APK без Android Studio

1. Распакуйте ZIP. На https://github.com/saturnfq-creator/TheGathering/upload/main загрузите **содержимое** архива (в том числе подпапки `app` и `tests`), а не сам ZIP.
2. Нажмите **Commit changes**. GitHub Actions автоматически запустит сборку после коммита в main.
3. Во вкладке Actions откройте последний успешный `Build The Gathering APK`, затем скачайте Artifacts → `TheGathering-v0.4-beta1-APK` (или старое имя артефакта, если GitHub пропустил скрытую `.github`).
4. Распакуйте скачанный с GitHub Actions архив и установите `app-debug.apk` на Android.

**Осторожно:** загрузка распакованных файлов через веб-интерфейс GitHub может не включить скрытую папку `.github`; тогда прежний workflow продолжит собирать новые исходники, но название артефакта останется прежним. Ниже версия 0.4 отражается в `app/build.gradle.kts`.

## Проверки

- `node tests/logic-smoke-test.cjs` — логика очереди, воспроизведения альбома, синхронизации состояния, отсутствие удалённых элементов.
- Браузерные тесты Chromium 390×844: неполный жест и возврат, свайпы в обе стороны, автопрокрутка в верх и вниз списка (160 треков), догрузка очереди, перетаскивание с изменением реального порядка JS, прокрутка длинного названия, библиотека и навигация.

**Ограничение:** Android SDK здесь недоступен, поэтому APK на Android в этой среде не компилировался и не тестировался. Жесты и анимации на телефоне, нагрев и реальные вылеты требуется проверить после сборки. Если возникают падения, понадобится logcat, чтобы не гадать о причине.

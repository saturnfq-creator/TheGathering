# The Gathering 0.9.0 Beta

Android-проект музыкального плеера **The Gathering**. Это исходники, **не APK**. Основа: 0.8 Beta; старая библиотека, поиск, просмотр альбомов, очередь, системное «Назад» и Media3 сохранены.

## Изменения 0.9

1. **Новая иконка запуска.** Использован предоставленный пользователем `Слой 3 (3).svg`: светлый/серый знак стопки обложек на тёмном фоне. Подготовлены адаптивный foreground, монохромная тематическая иконка, отдельные PNG для плотностей Android. Файл оригинала сохранён как `app/src/main/assets/launcher_logo_v09.svg`. **Логотип внутри интерфейса не менялся** (`brand_monochrome.png` и `gathering_logo_original.svg`). Превью — `launcher-preview-v09.png`.
2. **Подсветка движется вместе с играющей обложкой.** Контур и внешнее свечение прикреплены к каждой карточке, а не к неподвижной стопке. Во время горизонтального жеста контур исходной обложки тускнеет, затем подсветка плавно появляется у новой передней обложки. Стиль свечения, цветная фоновая аура и её палитра сохранены.
3. **Разворачивание очереди без изменения высоты содержимого.** Очередь всегда имеет фиксированный полный размер, а во время жеста перемещается целым композитным слоем (`translate3d`). Это устраняет постоянные пересчёты высоты списка и снижает риск белых вспышек в WebView. Дополнительно установлена тёмная native window theme, чтобы позади WebView не появлялся белый фон. **На реальном Android отсутствие мерцания ещё не подтверждено.**
4. **Более спокойный таймлайн.** Амплитуда волны уменьшена примерно до 0,6–2 px с более медленной фазой; стеклянное оформление и свечение сохранены.
5. **Перемешивание — внутри очереди.** Кнопка из плеера удалена, в заголовке очереди добавлена стеклянная кнопка Shuffle. При нажатии **физически перемешивается порядок всех оставшихся треков** (текущий трек не прерывается), новый порядок отображается в списке и передаётся в Media3 через `reorderQueue`. Автоматическое воспроизведение и ручной переход «Следующий» теперь следуют одинаковому порядку. Повторное нажатие перемешивает заново; скрытого режима случайного выбора следующей песни больше нет.

## Проверки

В среде разработки пройдены:

```sh
node --check app/src/main/assets/app.js
node tests/logic-smoke-test.cjs
python tests/browser-integration.py
python tests/v08-regressions.py
python tests/v09-regressions.py
```

Последний браузерный тест проверяет, что обрамление перемещается с карточкой и гаснет в жесте, Shuffle меняет настоящую очередь, её порядок передаётся нативному мосту, «Следующий» идёт по новому порядку, а окно очереди следует за пальцем **без изменения своей высоты**.

**Ограничения:** ни Gradle-сборка, ни реальная работа WebView/Media3 на Android в этой среде не проверялись. Производительность на слабых телефонах и исчезновение белого мерцания предстоит подтвердить после установки APK.

## Сборка APK через GitHub

1. Распаковать ZIP и загрузить **содержимое архива** в корень репозитория [saturnfq-creator/TheGathering](https://github.com/saturnfq-creator/TheGathering/upload/main), включая папку `.github`.
2. Нажать **Commit changes**. Workflow `Build The Gathering APK` запускается автоматически.
3. На странице **Actions** дождаться зелёной галочки, открыть запуск и скачать артефакт `TheGathering-v0.9-beta1-APK`.
4. Распаковать полученный артефакт, передать `app-debug.apk` на телефон и установить. Если текущая версия подписана другим ключом, может потребоваться удалить старое тестовое приложение (это не удаляет хранящиеся отдельно MP3).
5. Если сборка красная, прислать последние строки шага `Build APK`. Если APK вылетает, понадобится logcat.
